# メンバーの設定資料

## 物語の中心人物（闇に関与）

### 鈴木 太郎（CEO）

- 結社の末端。CRAYTE での実績を踏み台に幹部昇格を狙う野心家。
- 器量は小さく、批判に弱い。責任は下へ流しがち。
- 表向きは未来や挑戦を語る“良い社長”を演出する。
- 怪異を出世の道具として利用しようと考えている。

### 佐藤 健太（※中心人物）

- 鈴木と旧知で右腕。
- 会社発足時から裏の仕事をほぼ一人で回していた。
- 自らが主導した実験によって被験者を死なせ、“手を貸してしまった”罪悪感を抱える。
- 以降、怪異の取り扱いに対して鈴木と対立、失踪に至る。
- 失踪/消失の線が濃い。痕跡（ログ/プロフィール/404 誘導）が物語導線になる。
